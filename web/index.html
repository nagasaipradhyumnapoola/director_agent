The loop

From intent to evidence,
without the hand-wave.

Every task starts as a durable contract with acceptance criteria. Checks run first; model reasoning is optional and bounded. A newer failure supersedes an older pass. Completion is a state, not a claim.

01 / CONTRACT

Write the target down

Intent, deliverables, constraints, criteria, budgets, and the exact permissions the task may use.

02 / EXECUTE

Do the smallest real work

Deterministic checks first. Browser, ML, research, document, and container runners are scoped and bounded.

03 / PROVE

Bind evidence to state

Receipts carry hashes, evaluator versions, limitations, freshness, and the contract revision they belong to.

04 / IMPROVE

Change only through gates

Patch allowlist, isolated worktree, full tests, independent review, owner merge. The pipeline never pushes.
